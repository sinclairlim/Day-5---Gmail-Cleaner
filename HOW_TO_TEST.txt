⚡ QUICK START (10 Minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Validate Setup
───────────────────────
$ ./test-setup.sh

STEP 2: Get Google OAuth Credentials
────────────────────────────────────
1. Go to: https://console.cloud.google.com
2. Create new project → Enable Gmail API
3. Create OAuth credentials
4. Add redirect URI: http://localhost:8000/api/auth/callback
5. Copy Client ID & Secret

STEP 3: Get OpenAI API Key
──────────────────────────
1. Go to: https://platform.openai.com/api-keys
2. Create new key
3. Copy it

STEP 4: Configure Backend
─────────────────────────
$ cd backend
$ cp .env.example .env
# Edit .env with your credentials

STEP 5: Start Backend (Terminal 1)
──────────────────────────────────
$ cd backend
$ python3 -m venv venv
$ source venv/bin/activate
$ pip install -r requirements.txt
$ uvicorn app.main:app --reload

✅ Should see: "Uvicorn running on http://127.0.0.1:8000"

STEP 6: Start Frontend (Terminal 2)
───────────────────────────────────
$ cd frontend
$ npm install
$ npm run dev

✅ Should see: "Local: http://localhost:3000/"

STEP 7: Test the App
───────────────────
1. Open: http://localhost:3000
2. Click "Sign in with Google"
3. Complete OAuth (may show warning - this is normal)
4. Try scanning for spam emails
5. Review AI analysis
6. Select and delete test emails

🔧 COMMON ISSUES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Problem: "ModuleNotFoundError"
→ Solution: Activate venv first!
  $ source venv/bin/activate

Problem: "redirect_uri_mismatch"
→ Solution: Check Google Cloud Console
  Must be: http://localhost:8000/api/auth/callback

Problem: Blank page
→ Solution: Check browser console (F12)
  Verify backend is running

Problem: OpenAI errors
→ Solution: Verify API key starts with "sk-"
  Check you have credits

See TROUBLESHOOTING.md for more solutions.
